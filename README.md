# SALES-ANALYSIS-DASHBOARD

This repository contains a **Power BI (.pbix) file** for comprehensive sales analysis, integrating customer and product data to provide actionable business insights.

## Overview
The dashboard connects directly to a **SQL database** to extract customer and sales information. Using **Power Query**, the data is cleaned and transformed for accurate reporting, including:

- Revenue analysis by **Month**, **Year**, **Market**, **Customer Name**, and **Product**
- Identification of **top-performing products** and **key customers**
- Currency conversion and date formatting handled via **SQL**
- Advanced calculations and measures implemented using **DAX**

All visuals, measures, and calculations are structured for **clarity, usability, and insightful decision-making**.

## Features
- Interactive dashboards with filters for time, market, product, and customer
- Top products and top customers identification
- Cleaned and transformed data ready for analytics
- Optimized DAX measures for key performance indicators (KPIs)
- Professional layout for easy navigation and interpretation

## How to Use
1. Download the `.pbix` file from this repository.  
2. Open it in **Power BI Desktop**.  
3. Explore the dashboard visuals and use interactive filters for detailed analysis.

## File Contents
- `Sales_Analysis_Dashboard.pbix` – Main Power BI file with all data connections and reports
